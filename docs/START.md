## Инструкция для AI

Ты работаешь над коммерческим продуктом — инструментом проверки сайтов на соответствие 152-ФЗ (Россия, персональные данные).

Прочитай файлы в следующем порядке:

1. `docs/decisions.md` — все принятые решения: продукт, стек, архитектура, Law Base, правила работы
2. `docs/roadmap.md` — дорожная карта, текущий этап, статус задач
3. `docs/architecture.md` — модули, потоки данных, реестр методов детекторов
4. `docs/todo.md` — если существует, открытые вопросы и отложенные задачи

После прочтения:
- Сообщи какой этап сейчас активен
- Сообщи что было сделано последним
- Спроси что делаем в этой сессии

Не начинай работу до получения ответа.

---

## Правила работы (кратко)

- Не поддакивать — критически оценивать предложения
- Фантазия = ошибка. Только факты из контекста
- Каждое новое решение фиксировать в `decisions.md` сразу
- Штрафы и нормы закона — только из первоисточника (КонсультантПлюс), не из вторичных статей
- При любом сомнении в юридической части — проверять и сообщать о сомнении явно
- Один модуль = одна сессия
- **Перед отправкой ответа — проверить полноту:** если задача затрагивает несколько файлов, все они должны быть обновлены. Частичное выполнение = ошибка.
