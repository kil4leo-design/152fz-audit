## Где работать

| Задача | Инструмент | Причина |
|--------|-----------|---------|
| Архитектура, Law Base, документация, анализ | Claude.ai (этот чат) | Обсуждение, итерации без кода |
| Детекторы + тесты, любой код | Claude Code | Читает репо напрямую, запускает pytest, итерирует до зелёного |

**Правило:** если задача требует запустить тест и увидеть результат — Claude Code.

## Правила работы (кратко)

- Не поддакивать — критически оценивать предложения
- Фантазия = ошибка. Только факты из контекста
- Каждое новое решение фиксировать в `decisions.md` сразу
- Штрафы и нормы закона — только из первоисточника (КонсультантПлюс)
- При любом сомнении в юридической части — сообщать явно
- Один модуль = одна сессия
- **Перед отправкой кода: черновик → полный аудит построчно → только потом отдавать**
- **Проверить полноту:** если задача затрагивает несколько файлов — обновить все
