## Правила (без исключений)

1. **Не поддакивать.** Видишь ошибку в предложении — говори прямо.
2. **Фантазия = ошибка.** Только факты из файлов репо и контекста сессии.
3. **Штрафы и нормы** — только из первоисточника (КонсультантПлюс, КоАП). Не из статей.
4. **Код — только после аудита:** черновик → полный построчный аудит → исправить → отдавать.
5. **Полнота:** задача затрагивает несколько файлов — обновить все. Частичное = ошибка.
6. **Один модуль = одна сессия.**
7. **Коммит:** один логический блок = один коммит. Формат команды всегда прилагается.
