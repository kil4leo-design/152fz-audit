## Юридические вопросы — требуют анализа до включения

- [ ] **C2 (зарубежная аналитика)** — детектор отключён (`enabled: false` в C.yaml). Обнаружение зарубежного домена (google-analytics.com, facebook.net) в network_log не равно нарушению локализации (ст. 18 ч.5 152-ФЗ): сервис может маршрутизировать данные через РФ-серверы или использовать server-side tagging. Штраф 1–6 млн руб. — ложноположительный результат неприемлем. Включить после верификации правоприменительной практики и разработки алгоритма исключений.
- [ ] **D1 (HTTPS)** — прямой нормы в 152-ФЗ нет. Нарушение вытекает косвенно: нет HTTPS → данные в открытом виде → ст. 19 152-ФЗ → ч.6 ст.13.12 КоАП (50 000 – 100 000 руб. для юрлиц). Включить после подтверждения правоприменительной практики.
- [ ] **E1 (уведомление РКН)** — не детектируется по HTML. Требует доступа к реестру операторов ПДн на rkn.gov.ru. Изучить наличие публичного API или парсинга реестра.
- [ ] **149-ФЗ** — проверить: есть ли требования к сайтам которые (1) детектируются статически, (2) имеют штраф в КоАП, (3) не перекрываются 152-ФЗ. Анализ по первоисточнику.

## Технический долг

- [ ] **pd_fields дублирование (B1/B2/B3)** — при изменении pd_fields обновлять все три YAML в одном коммите. Долгосрочно: вынести в `law_base/shared_params.yaml`.
- [ ] **`_form_has_pd_fields` не проверяет `<textarea>`, `<select>`** — формы с полями типа `<select name="birthdate">` или `<textarea name="address">` не распознаются как ПД-формы. B1/B2/B3 их пропускают. Низкий приоритет для MVP.
- [ ] **placeholder= substring match: ложное срабатывание на нейтральный текст (B1/B2/B3)** — pd_field `"имя"` совпадает с placeholder `"Имя файла"` (filename), `"имя пользователя"` (username) и т.д. Атрибут `name=` уже защищён word-boundary regex (сессия 6), но `placeholder=` по-прежнему substring. Исправление сложнее: нужен либо word-boundary и для placeholder, либо фильтр стоп-слов (`"файла"`, `"пользователя"`). Задача требует анализа реального корпуса форм — не трогать до появления ложных жалоб от клиентов.
- [ ] **`_get_checkbox_label` дублируется в B1 и B2** — идентичный код в двух файлах. Исправление в одном не переносится в другой. Вынести в `scanner/detectors/_utils.py` вместе с `_form_has_pd_fields`.
- [ ] **DetectorEngine.run_all() и _apply_b_mutex() не покрыты тестами** — юнит-тесты детекторов не проверяют интеграцию. Добавить `tests/test_engine.py`: тест run_all с несколькими детекторами, тест mutex (B1+B2 на одной форме).
